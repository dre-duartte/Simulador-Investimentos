# Simulador-Investimentos
Projeto de Simulador de Investimentos desenvolvido em excel.
Este simulador de investimentos em fundos imobiliários, permite simular o valor de investimento mensal, o tempo de investimento, a taxa de rendimento, o patrimônio que será acumulado, bem como os dividendos mensais.
A fórmnula de excel VF - Valor Futuro, traz as simulações mencionadas, além de projetar demais cenários com temporabilidade de 2, 5, 10, 20 e 30 anos de investimento.
A fórmula de excel Procv - Procura Vertical, adequa os percentuais sugeridos de investimentos em cada fundo conforme o perfil de investidor selecionado, partindo de uma tabela de base de dados com os percentuais pré definidos.
O usuário deve preencher os valores nos campos em branco.
